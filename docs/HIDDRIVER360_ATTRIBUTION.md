# Third-party controller foundation

PSController integrates controller mapping concepts/source from **hiddriver360**
by EinTim23.

Upstream: https://github.com/EinTim23/hiddriver360

License: GNU General Public License v3.0 (GPL-3.0).

The imported controller-side files under `src/controller/hiddriver360/` retain
their upstream origin and are being adapted for PSController. PSController's
audio, AUX, headset and Xbox voice-routing work is separate project code.

No proprietary Xbox SDK/XDK libraries or binaries are included in this
repository.
